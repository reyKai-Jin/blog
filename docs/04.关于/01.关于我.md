# 关于我

我是**金凯**，一名同时做开发与影像创作的独立创作者。

我的工作大致可以分成两条线：一条是**代码**，负责把想法变成可用的产品；另一条是**镜头**，负责把想法变成能被看见的画面。AIGC 则把这两条线接了起来，让一个人也能完成过去需要一支团队才能完成的作品。

## 我的工作流

```text
想法
 ├─ 产品方向：需求 → 原型 → 前端实现 → 后端接口 → 上线
 └─ 影像方向：剧本 → 分镜 → 拍摄 → 剪辑 → 调色 → 声音
                ↑
             AIGC 辅助：关键帧、分镜图、概念图、配音
```

对我来说，开发和创作不是两件事：**结构感**让片子更清楚，**画面感**让产品更有温度。
