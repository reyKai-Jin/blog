闭包和 `this` 是 JavaScript 里最容易被面试、也最容易在真实代码里踩坑的两个概念。理解它们的关键都是「函数在哪里被定义、在哪里被调用」。

## 闭包是什么

函数可以访问它定义时所在作用域的变量，即使外部函数已经执行完毕：

```js
function createCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}

const counter = createCounter();
counter(); // 1
counter(); // 2
counter(); // 3
```

`createCounter` 已经返回，但内部函数仍然持有 `count` 的引用，这就是闭包。

形成条件：

1. 存在嵌套函数
2. 内部函数引用了外部函数的变量
3. 内部函数在外部函数之外被调用

## 典型用途

### 数据私有

```js
function createUser(name) {
  let visits = 0;

  return {
    getName: () => name,
    visit() {
      visits += 1;
      return visits;
    },
  };
}
```

外部无法直接访问 `visits`，只能通过暴露的方法操作。

### 缓存与记忆化

```js
function memoize(fn) {
  const cache = new Map();

  return function (key) {
    if (cache.has(key)) return cache.get(key);

    const result = fn(key);
    cache.set(key, result);
    return result;
  };
}
```

### 防抖

```js
function debounce(fn, delay = 300) {
  let timer;

  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

`timer` 被闭包保存，多次调用共享同一个定时器。

## 闭包与循环

经典问题：

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 输出 3 3 3
```

原因：`var` 只有一个 `i`，三个回调共享同一个变量，等回调执行时循环早已结束。

用 `let` 解决：

```js
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 输出 0 1 2
```

每次迭代都会创建新的块级绑定。

或者用立即执行函数（老写法）：

```js
for (var i = 0; i < 3; i++) {
  (function (j) {
    setTimeout(() => console.log(j), 0);
  })(i);
}
```

## this 的四种绑定

`this` 在函数被调用时确定，和它在哪里定义无关（箭头函数除外）。

### 1. 默认绑定

独立调用的函数，`this` 在非严格模式下指向全局对象，严格模式/模块中为 `undefined`：

```js
function show() {
  console.log(this);
}

show(); // window（非严格）或 undefined（严格）
```

### 2. 隐式绑定

通过对象调用，`this` 指向该对象：

```js
const user = {
  name: "金凯",
  say() {
    console.log(this.name);
  },
};

user.say(); // "金凯"
```

把方法赋给变量后，绑定会丢失：

```js
const say = user.say;
say(); // undefined（严格模式下可能报错）
```

### 3. 显式绑定

用 `call`、`apply`、`bind` 指定：

```js
function introduce(city) {
  console.log(`${this.name} 来自 ${city}`);
}

const person = { name: "金凯" };

introduce.call(person, "杭州");
introduce.apply(person, ["杭州"]);

const bound = introduce.bind(person);
bound("杭州");
```

- `call(thisArg, arg1, arg2, ...)`
- `apply(thisArg, [args])`
- `bind(thisArg)` 返回新函数，绑定永久生效

### 4. new 绑定

用 `new` 调用构造函数时，`this` 指向新创建的对象：

```js
function Person(name) {
  this.name = name;
}

const p = new Person("金凯");
```

优先级：`new` > 显式绑定 > 隐式绑定 > 默认绑定。

## 箭头函数

箭头函数没有自己的 `this`，它会捕获定义时外层作用域的 `this`：

```js
const user = {
  name: "金凯",
  say() {
    setTimeout(() => {
      console.log(this.name); // "金凯"
    }, 0);
  },
};

user.say();
```

如果用普通函数，`this` 在定时器回调里会丢失：

```js
const user2 = {
  name: "金凯",
  say() {
    setTimeout(function () {
      console.log(this.name); // undefined
    }, 0);
  },
};
```

箭头函数的限制：

- 不能用作构造函数
- 没有 `arguments`
- 不能通过 `call` / `apply` / `bind` 改变 `this`
- 不能作为对象的普通方法（`this` 不会指向对象）

## 常见 this 丢失场景

```js
// 事件回调
button.addEventListener("click", function () {
  console.log(this); // 指向 button
});

// 修复类方法丢失
class Player {
  constructor() {
    this.name = "player";
    this.play = this.play.bind(this);
  }

  play() {
    console.log(this.name);
  }
}
```

或者用类字段 + 箭头函数：

```js
class Player {
  name = "player";

  play = () => {
    console.log(this.name);
  };
}
```

## 小结

- 闭包让函数记住定义时的作用域，适合私有状态、缓存、防抖
- `this` 由调用方式决定，优先级是 `new` > 显式 > 隐式 > 默认
- 箭头函数继承外层 `this`，适合回调和类字段
- 方法被单独传递时，用 `bind` 或箭头函数固定 `this`
