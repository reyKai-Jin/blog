处理方法很多，分不清就用错。这篇按「要做什么」分类整理数组和对象的高频方法，顺便标注哪些会修改原数组。

## 数组遍历与转换

| 方法        | 用途             | 返回值             | 修改原数组 |
| ----------- | ---------------- | ------------------ | ---------- |
| `forEach`   | 遍历             | `undefined`        | 否         |
| `map`       | 映射             | 新数组             | 否         |
| `filter`    | 过滤             | 新数组             | 否         |
| `reduce`    | 聚合             | 任意               | 否         |
| `find`      | 找第一个匹配项   | 元素或 `undefined` | 否         |
| `findIndex` | 找索引           | 索引或 `-1`        | 否         |
| `some`      | 是否至少一个满足 | 布尔               | 否         |
| `every`     | 是否全部满足     | 布尔               | 否         |
| `flat`      | 拍平             | 新数组             | 否         |
| `sort`      | 排序             | 原数组             | **是**     |
| `reverse`   | 反转             | 原数组             | **是**     |
| `splice`    | 增删元素         | 被删除的元素       | **是**     |

```js
const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8, 10]
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]
const sum = numbers.reduce((acc, n) => acc + n, 0); // 15
const firstBig = numbers.find(n => n > 3); // 4
const hasNegative = numbers.some(n => n < 0); // false
const allPositive = numbers.every(n => n > 0); // true
```

## reduce 的三种用法

```js
// 1. 求和
const total = [1, 2, 3].reduce((acc, n) => acc + n, 0);

// 2. 分组
const users = [
  { name: "a", role: "admin" },
  { name: "b", role: "user" },
  { name: "c", role: "admin" },
];

const byRole = users.reduce((acc, user) => {
  (acc[user.role] ||= []).push(user);
  return acc;
}, {});

// 3. 数组去重
const unique = [1, 2, 2, 3].reduce((acc, n) => {
  if (!acc.includes(n)) acc.push(n);
  return acc;
}, []);
```

初始值很重要：没有初始值且数组为空时会抛 `TypeError`。

## 排序

```js
const nums = [10, 2, 33, 4];

// 默认按字符串排序
nums.sort(); // [10, 2, 33, 4]

// 数字排序
nums.sort((a, b) => a - b); // [2, 4, 10, 33]

// 不修改原数组
const sorted = nums.toSorted((a, b) => a - b);
```

`sort` 原地修改，在 React / Vue 的响应式数据里容易引发意外更新。ES2023 提供了 `toSorted`、`toReversed`、`toSpliced`、`with` 等不可变方法。

排序对象：

```js
const posts = [{ date: "2026-01-02" }, { date: "2026-03-01" }];

posts.toSorted((a, b) => new Date(b.date) - new Date(a.date));
```

## 查找与判断

```js
const arr = [1, 2, 3];

arr.includes(2); // true
arr.indexOf(2); // 1
arr.at(-1); // 3，支持负索引

// 对象数组按字段查找
const list = [{ id: 1 }, { id: 2 }];
list.find(item => item.id === 2);
```

`includes` 用 SameValueZero 比较，可以找到 `NaN`；`indexOf` 找不到 `NaN`。

## 扁平化与扩展

```js
[1, [2, [3]]].flat(); // [1, 2, [3]]
[1, [2, [3]]].flat(Infinity); // [1, 2, 3]
[1, 2].flatMap(n => [n, n * 2]); // [1, 2, 2, 4]

Array.from("abc"); // ["a", "b", "c"]
Array.from({ length: 3 }, (_, i) => i); // [0, 1, 2]

Array.isArray([]); // true
```

## 对象常用方法

```js
const user = { name: "金凯", age: 28 };

Object.keys(user); // ["name", "age"]
Object.values(user); // ["金凯", 28]
Object.entries(user); // [["name", "金凯"], ["age", 28]]

Object.fromEntries([
  ["name", "金凯"],
  ["age", 28],
]); // { name: "金凯", age: 28 }
```

### 合并与拷贝

```js
const base = { theme: "dark", lang: "zh" };
const custom = { theme: "light" };

// 浅合并
const config = { ...base, ...custom }; // { theme: "light", lang: "zh" }
const config2 = Object.assign({}, base, custom);

// 浅拷贝
const copy = { ...user };
const copy2 = Object.assign({}, user);
```

嵌套对象仍然共享引用，需要深拷贝：

```js
const deep = structuredClone(user);
```

`structuredClone` 支持 Map、Set、Date、ArrayBuffer，但不支持函数和 DOM 节点。

### 冻结与密封

```js
Object.freeze(obj); // 不能增删改属性
Object.isFrozen(obj); // true

Object.seal(obj); // 不能增删，但可以修改已有属性
```

两者都是浅操作。

### 属性判断

```js
"name" in user; // true，包含原型链
Object.hasOwn(user, "name"); // true，只查自身
user.hasOwnProperty("name"); // 也可以，但对象可能覆盖该方法
```

## 展开与解构

```js
const [first, ...rest] = [1, 2, 3];
const { name, ...others } = user;

const merged = { ...a, ...b };
```

注意：对象展开是浅拷贝，`...` 不复制原型，也不复制不可枚举属性。

## 现代语法

```js
// 可选链
user?.profile?.avatar;
list?.[0];

// 空值合并
const theme = user.theme ?? "dark"; // 只有 null / undefined 才回退
const name = user.name || "匿名"; // 空字符串也会回退

// 逻辑赋值
user.name ??= "匿名";
user.count ||= 0;
user.role &&= "admin";
```

## 小结

- 遍历用 `forEach`，转换用 `map`，筛选用 `filter`，聚合用 `reduce`
- 注意 `sort` / `reverse` / `splice` 会修改原数组
- 深拷贝用 `structuredClone`
- `??` 只处理 `null` / `undefined`，`||` 会处理所有假值
- 新项目优先用不可变方法，减少共享状态带来的 bug
