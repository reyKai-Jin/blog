把一堆散落在硬盘里的文章、短片和 AIGC 实验，收拢成一个可以长期维护的个人站点，是我一直想做的事。这篇记录站点的搭建过程，也当作这个栏目正式开张的第一篇。

<!-- more -->

## 为什么选 VitePress + Teek

个人站的需求其实很清晰：

- **写作要快**：Markdown 写完就能发布，不想折腾后台。
- **样子要像自己**：不要千篇一律的文档模板。
- **能放视频和图片**：作品展示比纯文字重要。
- **部署免费且稳定**：静态站点最省心。

VitePress 负责「Markdown → 静态站点」这条主链路，Teek 在默认主题上补齐了博客首页、文章列表、分类标签、归档、搜索等能力，两者组合正好覆盖我的需求。

## 目录结构

站点内容全部放在 `docs/` 下，按栏目建立带序号的中文目录：

```text
docs
├─ index.md                 # 首页（Teek 博客风格）
├─ 01.技术文章
│  ├─ 目录.md               # 栏目索引（catalogue 目录页）
│  ├─ 前端
│  └─ 后端
├─ 02.视频作品
├─ 03.AIGC作品
├─ 04.关于
├─ @pages                   # 归档 / 分类 / 标签等功能页
└─ .vitepress               # 站点与主题配置
```

带序号的前缀决定了侧边栏顺序，Teek 会根据目录结构自动生成侧边栏，不需要手写配置。

## 关键配置

首页使用 Teek 的博客风格，在 `.vitepress/teek-config.ts` 里打开：

```ts
export const teekConfig = defineTeekConfig({
  teekHome: true,
  vpHome: false,
  blogger: {
    name: "金凯",
    slogan: "写代码，也拍故事。前端 / 后端 / 影像 / AIGC",
    avatar: "/avatar.svg",
  },
  banner: {
    name: "金凯的个人站",
    bgStyle: "fullImg",
    imgSrc: ["/blog/bg1.webp", "/blog/bg2.webp", "/blog/bg3.webp"],
    descStyle: "types",
  },
});
```

文章通过 `frontmatter` 声明分类、标签、封面和永久链接：

```yaml
---
title: 从零搭建个人站：VitePress + Teek
date: 2026-11-14 10:00:00
permalink: /tech/frontend/build-with-vitepress-teek
categories:
  - 技术文章
  - 前端
tags:
  - VitePress
  - Teek
coverImg: /blog/bg3.webp
top: true
---
```

`permalink` 一旦确定就不要随意改，它是文章对外分享的固定地址。

## 本地运行

```bash
# 安装依赖
pnpm install

# 启动文档站
pnpm docs:dev

# 构建
pnpm docs:build

# 预览构建结果
pnpm docs:preview
```

## 部署

静态站点适合托管在任何静态平台。以 GitHub Pages 为例，构建产物在 `docs/.vitepress/dist`，推送后即可访问。
