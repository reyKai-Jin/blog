「把文件拖进来就能上传」看起来很简单，但拖放事件流、默认行为、文件读取各有一堆细节。这篇把这条链路完整走一遍。

## 拖放事件流

### 被拖拽元素

```html
<div id="card" draggable="true">拖我</div>
```

```js
const card = document.querySelector("#card");

card.addEventListener("dragstart", event => {
  event.dataTransfer.setData("text/plain", "card-1");
  event.dataTransfer.effectAllowed = "move";
});

card.addEventListener("dragend", event => {
  if (event.dataTransfer.dropEffect === "none") {
    console.log("拖拽被取消或放置失败");
  }
});
```

### 放置区域

```js
const zone = document.querySelector("#zone");

zone.addEventListener("dragover", event => {
  event.preventDefault(); // 关键：不阻止默认行为就无法触发 drop
  event.dataTransfer.dropEffect = "copy";
});

zone.addEventListener("drop", event => {
  event.preventDefault();
  const text = event.dataTransfer.getData("text/plain");
  console.log("放下了", text);
});
```

### 事件顺序

1. `dragstart`
2. 拖动过程中在放置区域不断触发 `dragenter` / `dragover`
3. 放下时触发 `drop`
4. 最后触发 `dragend`

`dragover` 里必须调用 `preventDefault()`，否则浏览器认为这里不接受放置，`drop` 不会触发。

## dataTransfer

| 方法 / 属性            | 说明                                         |
| ---------------------- | -------------------------------------------- |
| `setData(type, value)` | 写入数据，常见 `text/plain`、`text/uri-list` |
| `getData(type)`        | 读取数据，只能在 `drop` 中读取               |
| `clearData()`          | 清空                                         |
| `files`                | 拖入的文件列表（FileList）                   |
| `items`                | 数据项列表，可读字符串或文件                 |
| `effectAllowed`        | 源端声明允许的操作                           |
| `dropEffect`           | 目标端声明光标效果                           |

`setData` 只能在 `dragstart` 里调用，`getData` 只能在 `drop` 里调用，其他时候拿到的都是空字符串。

## File API

### 选择文件

```html
<input id="picker" type="file" accept="image/*" multiple />
```

```js
const picker = document.querySelector("#picker");

picker.addEventListener("change", () => {
  const files = Array.from(picker.files);

  files.forEach(file => {
    console.log(file.name, file.type, file.size);
  });
});
```

`File` 继承自 `Blob`，常用属性：

- `name`：文件名
- `size`：字节数
- `type`：MIME 类型，可能为空
- `lastModified`：最后修改时间戳

### 读取文件

```js
function readAsText(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();

    reader.onload = () => resolve(reader.result);
    reader.onerror = () => reject(reader.error);
    reader.readAsText(file);
  });
}

function readAsDataURL(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result);
    reader.onerror = () => reject(reader.error);
    reader.readAsDataURL(file);
  });
}
```

| 方法                       | 结果                          |
| -------------------------- | ----------------------------- |
| `readAsText(file)`         | 文本字符串                    |
| `readAsDataURL(file)`      | Base64 Data URL，适合预览小图 |
| `readAsArrayBuffer(file)`  | 二进制缓冲区                  |
| `readAsBinaryString(file)` | 已废弃，不要再用              |

大文件不要用 `readAsDataURL`，Base64 会让体积膨胀约 33%。

### 预览图片

```js
function previewImage(file, imgElement) {
  const url = URL.createObjectURL(file);
  imgElement.src = url;

  // 用完记得释放
  imgElement.onload = () => URL.revokeObjectURL(url);
}
```

## 拖拽上传

```html
<div id="drop-zone">
  <p>把图片拖到这里，或点击选择</p>
  <input id="file-input" type="file" accept="image/*" multiple hidden />
</div>
```

```js
const zone = document.querySelector("#drop-zone");
const input = document.querySelector("#file-input");

zone.addEventListener("click", () => input.click());

input.addEventListener("change", () => {
  uploadFiles(input.files);
});

zone.addEventListener("dragover", event => {
  event.preventDefault();
  zone.classList.add("is-active");
});

zone.addEventListener("dragleave", () => {
  zone.classList.remove("is-active");
});

zone.addEventListener("drop", event => {
  event.preventDefault();
  zone.classList.remove("is-active");

  const files = Array.from(event.dataTransfer.files);
  uploadFiles(files);
});

async function uploadFiles(files) {
  for (const file of files) {
    const formData = new FormData();
    formData.append("file", file);

    const response = await fetch("/api/upload", {
      method: "POST",
      body: formData,
    });

    console.log(file.name, await response.json());
  }
}
```

## 常见坑

- 忘记在 `dragover` 里 `preventDefault()`：`drop` 永远不触发
- 拖到子元素上触发 `dragleave`：可以用 `dragenter` / `dragleave` 计数，或者用 `relatedTarget` 判断
- 拖拽时整个页面被浏览器打开文件：在 `window` 上监听 `dragover` / `drop` 并阻止默认行为
- 只校验扩展名：`file.type` 和扩展名都可以伪造，安全校验必须放在服务端
- 大文件一次性读进内存：使用分片上传或流式上传

## 小结

- 拖放的三个关键：`draggable`、`dragover.preventDefault()`、`drop`
- 文件信息从 `dataTransfer.files` 或 `input.files` 获取
- 预览用 `URL.createObjectURL`，用完 `revokeObjectURL`
- 上传校验以服务端为准
