响应式不是「写三个断点把页面塞进去」，而是让布局在任意宽度下都成立。媒体查询负责页面级，容器查询负责组件级。

## 视口基础

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

没有这一行，移动端会把页面按 980px 渲染再缩小，媒体查询全部失效。

## 移动优先

先写小屏样式，再用 `min-width` 逐步增强：

```css
.grid {
  display: grid;
  gap: 16px;
  grid-template-columns: 1fr;
}

@media (min-width: 640px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

常见断点（不是标准，按内容需要调整）：

| 宽度             | 典型设备       |
| ---------------- | -------------- |
| `< 640px`        | 手机           |
| `640px - 1023px` | 平板、小笔记本 |
| `>= 1024px`      | 桌面           |
| `>= 1280px`      | 大屏           |

## 媒体查询语法

```css
/* 屏幕且宽度在 640 到 1023 之间 */
@media (min-width: 640px) and (max-width: 1023px) {
}

/* 深色模式 */
@media (prefers-color-scheme: dark) {
}

/* 减少动态效果 */
@media (prefers-reduced-motion: reduce) {
}

/* 横屏 */
@media (orientation: landscape) {
}
```

多用特性查询，少依赖具体设备型号。

## 流式尺寸

### clamp

```css
.title {
  /* 最小 24px，理想值随视口变化，最大 40px */
  font-size: clamp(24px, 2.5vw + 16px, 40px);
}
```

### min + vw

```css
.container {
  width: min(1200px, 100% - 48px);
  margin-inline: auto;
}
```

比 `max-width` + `padding` 更直接。

### 视口单位

| 单位        | 含义                           |
| ----------- | ------------------------------ |
| `vw` / `vh` | 视口宽 / 高的 1%               |
| `dvh`       | 动态视口高度，随地址栏收起变化 |
| `svh`       | 最小视口高度                   |
| `lvh`       | 最大视口高度                   |

移动端全屏布局优先用 `dvh`，`100vh` 在地址栏存在时会溢出。

```css
.hero {
  min-height: 100dvh;
}
```

## 容器查询

媒体查询看的是视口，容器查询看的是父容器。组件在侧栏和主区域可以自动切换布局：

```css
.card-list {
  container-type: inline-size;
  container-name: cards;
}

@container cards (min-width: 480px) {
  .card-list__item {
    display: flex;
    gap: 16px;
  }
}
```

- `container-type: inline-size` 表示按宽度查询
- 容器必须有明确的宽度来源（块级元素默认可）
- 容器查询不能查询自身，只能查询祖先容器

## 响应式图片

```html
<picture>
  <source media="(min-width: 1024px)" srcset="/cover-large.webp" />
  <source media="(min-width: 640px)" srcset="/cover-medium.webp" />
  <img src="/cover-small.webp" alt="封面" loading="lazy" />
</picture>
```

或者用 `srcset` + `sizes` 让浏览器自己选：

```html
<img
  src="/cover-small.webp"
  srcset="/cover-small.webp 640w, /cover-medium.webp 1280w, /cover-large.webp 1920w"
  sizes="(min-width: 1024px) 960px, 100vw"
  alt="封面"
/>
```

## 响应式排版

```css
:root {
  --step-0: clamp(16px, 1vw + 12px, 18px);
  --step-1: clamp(20px, 1.2vw + 14px, 24px);
  --step-2: clamp(26px, 1.6vw + 18px, 32px);
}

body {
  font-size: var(--step-0);
  line-height: 1.7;
}

h2 {
  font-size: var(--step-2);
}
```

比给每个断点单独写字号更好维护。

## 测试清单

- 320px 宽度下是否出现横向滚动
- 文字放大到 200% 是否还能用
- 长英文单词、URL、代码块是否撑破容器
- 触控目标是否至少 44×44px
- 暗色模式和横屏是否验证过

## 小结

- 移动优先，先单列再增强
- 流式尺寸用 `clamp` / `min`
- 组件级响应式用容器查询
- 移动端全屏高度用 `dvh`
- 响应式最终看内容，不是看设备型号
