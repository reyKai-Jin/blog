Flex 负责一维排列，Grid 负责二维布局。页面级骨架、卡片墙、仪表盘，用 Grid 往往比 Flex 嵌套更直接。

<!-- more -->

## 基础用法

```html
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
</div>
```

```css
.grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}
```

- `1fr` 表示一份剩余空间
- `gap` 同时控制行列间距
- 默认子项按行依次填充

## 定义行列

```css
.grid {
  display: grid;
  grid-template-columns: 240px 1fr 240px;
  grid-template-rows: 64px auto 64px;
  gap: 12px;
}
```

### repeat 与 fr

```css
/* 三列等宽 */
.cols-3 {
  grid-template-columns: repeat(3, 1fr);
}

/* 固定列 + 自适应列 */
.sidebar-layout {
  grid-template-columns: 240px minmax(0, 1fr);
}
```

`minmax(0, 1fr)` 和 Flex 里的 `min-width: 0` 作用类似，防止内容撑破列宽。

### auto-fill 与 auto-fit

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 16px;
}
```

- `auto-fill`：有多少空间就排多少列，空列也保留
- `auto-fit`：空列会被合并，剩余项目拉伸填满

卡片墙通常用 `auto-fill`，希望最后一行卡片被拉伸时用 `auto-fit`。

## 网格线定位

网格线从 1 开始，`-1` 表示最后一条线。

```css
.item {
  grid-column: 1 / 3; /* 从第 1 条竖线到第 3 条竖线，跨 2 列 */
  grid-row: 2 / 4;
}
```

简写：

```css
.item {
  grid-column: span 2; /* 跨 2 列 */
  grid-row: span 1;
}
```

## 命名区域

页面骨架用 `grid-template-areas` 最直观：

```css
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 64px 1fr 64px;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
  gap: 16px;
}

.page__header {
  grid-area: header;
}
.page__sidebar {
  grid-area: sidebar;
}
.page__main {
  grid-area: main;
}
.page__footer {
  grid-area: footer;
}
```

响应式时只需要重新声明 `grid-template-areas`：

```css
@media (max-width: 768px) {
  .page {
    grid-template-columns: 1fr;
    grid-template-rows: auto;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
  }
}
```

## 对齐

```css
.grid {
  justify-items: stretch; /* 单元格内水平对齐 */
  align-items: stretch; /* 单元格内垂直对齐 */
  justify-content: center; /* 整个网格在容器内水平对齐 */
  align-content: start; /* 整个网格在容器内垂直对齐 */
}
```

单个项目可以覆盖：

```css
.item {
  justify-self: end;
  align-self: center;
}
```

## 自动放置

```css
.grid {
  grid-auto-flow: row; /* 默认，按行填充 */
}

.grid--dense {
  grid-auto-flow: row dense; /* 尽量填满前面的空洞 */
}
```

`dense` 适合图片瀑布流一类场景，但会改变阅读顺序，对可访问性不友好，谨慎使用。

## 隐式网格

```css
.grid {
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 180px; /* 自动生成的行高 */
}
```

项目数量超出定义的网格后会生成隐式行列，用 `grid-auto-rows` / `grid-auto-columns` 控制尺寸。

## Grid 与 Flex 怎么选

| 场景                       | 推荐 |
| -------------------------- | ---- |
| 一行按钮、导航、表单行     | Flex |
| 卡片墙、仪表盘、页面骨架   | Grid |
| 需要行列同时对齐           | Grid |
| 内容宽度不定、需要自然分布 | Flex |

两者不是互斥的：Grid 容器里的单元格可以再放一个 Flex 容器。

## 常见坑

- 列宽被长内容撑开：用 `minmax(0, 1fr)`
- `1fr` 在内容过长时不会自动缩小：`fr` 的最小值是 `auto`
- `auto-fit` 和 `auto-fill` 在项目数少于列数时表现不同
- 旧版浏览器对 `gap` 支持不完整，现代浏览器已无此问题

## 小结

- Grid 适合二维布局，`repeat` + `fr` + `gap` 是基本盘
- `minmax(260px, 1fr)` + `auto-fill` 是卡片墙通用解
- 页面骨架用 `grid-template-areas` 最清晰
- 别忘了 `minmax(0, 1fr)` 防溢出
