Flex 解决的是「一维排列 + 剩余空间分配」。导航栏、卡片行、居中、表单行，用 Flex 都能写得很短。

<!-- more -->

## 容器与项目

```html
<div class="flex">
  <div class="item">A</div>
  <div class="item">B</div>
  <div class="item">C</div>
</div>
```

```css
.flex {
  display: flex;
}
```

容器上的属性控制「怎么排」，项目上的属性控制「怎么分」。

## 容器属性

### flex-direction

```css
.row {
  flex-direction: row; /* 默认，从左到右 */
}
.row-reverse {
  flex-direction: row-reverse;
}
.column {
  flex-direction: column;
}
.column-reverse {
  flex-direction: column-reverse;
}
```

注意：切换成 `column` 后，主轴变成垂直方向，`justify-content` 和 `align-items` 的作用方向也随之交换。

### flex-wrap

```css
.wrap {
  flex-wrap: wrap; /* 默认 nowrap，会挤压子项 */
}
```

做多行卡片时几乎一定要加 `wrap`。

### justify-content

主轴对齐：

| 值              | 效果                 |
| --------------- | -------------------- |
| `flex-start`    | 靠起点               |
| `flex-end`      | 靠终点               |
| `center`        | 居中                 |
| `space-between` | 两端对齐，中间等分   |
| `space-around`  | 每个项目两侧都有间距 |
| `space-evenly`  | 所有间距相等         |

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

### align-items

交叉轴对齐：

```css
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### gap

```css
.list {
  display: flex;
  gap: 16px;
}
```

`gap` 比给子项写 margin 更干净，不会在首尾留下多余间距。

## 项目属性

### flex-grow / flex-shrink / flex-basis

```css
.item {
  flex-grow: 1; /* 有剩余空间时放大 */
  flex-shrink: 1; /* 空间不足时缩小 */
  flex-basis: 0; /* 初始尺寸 */
}
```

简写：

```css
.a {
  flex: 1; /* 等价于 1 1 0%，平分剩余空间 */
}

.b {
  flex: 0 0 240px; /* 固定 240px，不放大不缩小 */
}

.c {
  flex: 0 1 auto; /* 默认值，按内容宽度 */
}
```

最常见的三栏布局：

```css
.layout {
  display: flex;
}

.sidebar {
  flex: 0 0 240px;
}

.content {
  flex: 1;
  min-width: 0;
}
```

`min-width: 0` 很关键，后面会解释。

### align-self

单独覆盖某个项目的交叉轴对齐：

```css
.item--top {
  align-self: flex-start;
}
```

## 经典布局模板

### 水平垂直居中

```css
.center {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

### 导航：左 Logo，右菜单

```css
.nav {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}
```

### 卡片底部按钮对齐

```css
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}

.card__body {
  flex: 1;
}
```

卡片高度一致时，按钮自然沉到底部。

### 输入框 + 按钮

```css
.search {
  display: flex;
}

.search input {
  flex: 1;
  min-width: 0;
}
```

## 经典坑：子项被内容撑破

Flex 项目默认 `min-width: auto`，内容（长文本、`pre`、图片）会把项目撑得比预期宽，导致容器溢出。

```css
.item {
  flex: 1;
  min-width: 0; /* 允许收缩到内容宽度以下 */
  overflow: hidden;
}
```

同理，垂直方向对应 `min-height: 0`。

另一个常见问题：`flex-basis: 0` 配合 `padding` 时，`border-box` 不影响 flex-basis 计算，宽度可能和直觉不一致。需要精确控制时用 `width` + `flex-shrink`。

## 什么时候不用 Flex

- 二维网格（行列同时对齐）用 Grid
- 一行文字的自然换行不需要 Flex
- 大量列表项且要虚拟滚动时，Flex 不是瓶颈，别乱优化

## 小结

- 容器控制方向、换行、主轴和交叉轴对齐
- 项目用 `flex: grow shrink basis` 分配空间
- 固定侧栏 + 自适应主区是最高频组合
- 别忘了 `min-width: 0`，否则长内容会把布局撑爆
