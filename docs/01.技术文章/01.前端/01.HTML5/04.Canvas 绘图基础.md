凡是图表、签板、图片裁剪、小游戏这类需求，`<canvas>` 都是绕不开的。这篇从坐标系开始，把 2D 上下文最常用的绘制能力过一遍。

## 创建画布

```html
<canvas id="board" width="800" height="450">你的浏览器不支持 canvas。</canvas>
```

```js
const canvas = document.querySelector("#board");
const ctx = canvas.getContext("2d");
```

关键区别：

- `width` / `height` 属性是**画布缓冲区**尺寸，不写默认 300×150
- CSS 的 `width` / `height` 只是显示尺寸，会把画布拉伸

```js
// 正确：通过属性改缓冲区尺寸
canvas.width = 800;
canvas.height = 450;
```

## 坐标系与基础绘制

Canvas 的坐标原点在左上角，x 向右增大，y 向下增大。

```js
// 矩形
ctx.fillStyle = "#2563eb";
ctx.fillRect(20, 20, 120, 80); // 填充

ctx.strokeStyle = "#111827";
ctx.lineWidth = 2;
ctx.strokeRect(20, 20, 120, 80); // 描边

ctx.clearRect(0, 0, canvas.width, canvas.height); // 清空
```

## 路径

```js
ctx.beginPath();
ctx.moveTo(40, 40); // 起点
ctx.lineTo(200, 40);
ctx.lineTo(120, 160);
ctx.closePath(); // 回到起点

ctx.fillStyle = "#f59e0b";
ctx.fill();
ctx.stroke();
```

常用路径 API：

| 方法                               | 说明               |
| ---------------------------------- | ------------------ |
| `moveTo(x, y)`                     | 移动画笔，不画线   |
| `lineTo(x, y)`                     | 画直线到目标点     |
| `arc(x, y, r, start, end)`         | 画圆弧，角度用弧度 |
| `quadraticCurveTo(cpx, cpy, x, y)` | 二次贝塞尔曲线     |
| `bezierCurveTo(...)`               | 三次贝塞尔曲线     |
| `rect(x, y, w, h)`                 | 添加矩形路径       |
| `closePath()`                      | 闭合当前路径       |

```js
// 画一个圆
ctx.beginPath();
ctx.arc(400, 225, 80, 0, Math.PI * 2);
ctx.fill();
```

## 文本

```js
ctx.font = "600 32px system-ui, sans-serif";
ctx.textAlign = "center";
ctx.textBaseline = "middle";
ctx.fillStyle = "#111827";
ctx.fillText("金凯的个人站", 400, 225);

// 描边文字
ctx.strokeStyle = "#fff";
ctx.lineWidth = 3;
ctx.strokeText("金凯的个人站", 400, 225);
```

`measureText(text).width` 可以拿到文本宽度，用于居中或截断。

## 图片

```js
const img = new Image();
img.src = "/blog/bg1.webp";

img.onload = () => {
  // 按原始尺寸绘制
  ctx.drawImage(img, 50, 50);

  // 缩放绘制
  ctx.drawImage(img, 50, 50, 240, 135);

  // 裁剪后绘制：源图 0,0,640,360 → 目标 50,50,320,180
  ctx.drawImage(img, 0, 0, 640, 360, 50, 50, 320, 180);
};
```

图片必须加载完成才能绘制，直接 `drawImage` 未加载的图片不会报错，只是什么也不显示。

## 状态保存与变换

```js
ctx.save(); // 保存当前状态

ctx.translate(400, 225); // 移动原点
ctx.rotate(Math.PI / 4); // 旋转 45 度
ctx.scale(1.5, 1.5); // 缩放

ctx.fillRect(-50, -50, 100, 100);

ctx.restore(); // 恢复状态
```

`save()` / `restore()` 要成对出现，否则变换会不断叠加，越画越偏。

## 高分屏适配

在 `devicePixelRatio > 1` 的屏幕上，画布会被放大导致模糊。解决方法是按设备像素比放大缓冲区，再用 CSS 缩回：

```js
function setupCanvas(canvas) {
  const dpr = window.devicePixelRatio || 1;
  const rect = canvas.getBoundingClientRect();

  canvas.width = rect.width * dpr;
  canvas.height = rect.height * dpr;
  canvas.style.width = `${rect.width}px`;
  canvas.style.height = `${rect.height}px`;

  const ctx = canvas.getContext("2d");
  ctx.scale(dpr, dpr);
  return ctx;
}
```

之后绘制时继续使用 CSS 像素坐标即可。

## 动画循环

```js
const dpr = window.devicePixelRatio || 1;
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

let x = 0;
let rafId;

function resize() {
  const rect = canvas.getBoundingClientRect();
  canvas.width = rect.width * dpr;
  canvas.height = rect.height * dpr;
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
}

function draw() {
  const rect = canvas.getBoundingClientRect();
  ctx.clearRect(0, 0, rect.width, rect.height);

  ctx.beginPath();
  ctx.arc(x, rect.height / 2, 24, 0, Math.PI * 2);
  ctx.fillStyle = "#2563eb";
  ctx.fill();

  x = (x + 3) % rect.width;
  rafId = requestAnimationFrame(draw);
}

resize();
draw();

window.addEventListener("resize", resize);
// 页面销毁或组件卸载时取消
// cancelAnimationFrame(rafId);
```

要点：

- 每帧先 `clearRect`，否则会留下残影
- 用 `requestAnimationFrame` 而不是 `setInterval`
- 时间相关的动画用时间戳计算位移，避免不同刷新率下速度不一致
- 组件卸载时一定要 `cancelAnimationFrame`

## 常见场景

- 图片裁剪 / 缩略图：`drawImage` 的裁剪版本 + `toDataURL()`
- 图表：柱状图、折线图本质都是 `fillRect` / `lineTo`
- 签名板：监听鼠标或触摸事件，逐点 `lineTo`
- 小游戏：清屏 → 计算 → 绘制，标准循环

## 小结

- 区分画布缓冲区尺寸和 CSS 显示尺寸
- 路径操作要 `beginPath()` 开头
- 变换前后用 `save()` / `restore()`
- 高分屏按 DPR 放大缓冲区
- 动画用 `requestAnimationFrame`，卸载时取消
