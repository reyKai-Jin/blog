视频作品页要用到 `<video>`，那就把媒体元素一次讲清楚：属性怎么配、格式怎么选、自动播放为什么被拦、字幕怎么挂。

<!-- more -->

## 基本用法

```html
<video src="/videos/city-night.mp4" poster="/blog/bg1.webp" controls preload="metadata" width="960" height="540">
  你的浏览器不支持 video 标签。
</video>

<audio src="/audio/bgm.mp3" controls preload="none"></audio>
```

`<video>` 和 `<audio>` 之间的文字是降级内容，只在浏览器不支持该标签时显示。

## 多格式与多码率

```html
<video controls poster="/blog/bg1.webp">
  <source src="/videos/city-night.webm" type="video/webm" />
  <source src="/videos/city-night.mp4" type="video/mp4" />
  <track kind="subtitles" src="/videos/city-night.zh.vtt" srclang="zh" label="中文字幕" default />
  你的浏览器不支持 video 标签。
</video>
```

浏览器会按顺序选择第一个能播放的源：

| 格式 | 编码        | 兼容性                  | 建议               |
| ---- | ----------- | ----------------------- | ------------------ |
| MP4  | H.264 + AAC | 最好                    | 必备的兜底格式     |
| WebM | VP9 + Opus  | Chrome / Firefox / Edge | 体积更小，可作首选 |
| Ogg  | Theora      | 较老                    | 一般不需要         |

用 `type` 明确 MIME 类型，浏览器才能跳过不支持的源，避免多余请求。

## 常用属性

| 属性               | 说明                                         |
| ------------------ | -------------------------------------------- |
| `controls`         | 显示原生控制条                               |
| `autoplay`         | 自动播放，受浏览器策略限制                   |
| `muted`            | 静音                                         |
| `loop`             | 循环播放                                     |
| `playsinline`      | iOS 上内联播放，不自动全屏                   |
| `preload`          | `none` / `metadata` / `auto`，提示预加载程度 |
| `poster`           | 视频封面图（仅 `video`）                     |
| `width` / `height` | 初始尺寸，避免布局抖动                       |

```html
<!-- 移动端常见的静音自动播放背景视频 -->
<video src="/videos/bg.mp4" autoplay muted loop playsinline preload="metadata"></video>
```

## 自动播放策略

各浏览器的规则基本一致：

- **有声自动播放几乎都会被拦截**，尤其是移动端
- **静音自动播放**通常允许，但 iOS 低电量模式仍可能阻止
- 用户与页面产生交互后，才有资格调用 `play()`

所以正确姿势是：默认 `muted`，能播就播，不能播就展示封面和播放按钮。

```js
const video = document.querySelector("video");

async function tryPlay() {
  try {
    await video.play();
  } catch (error) {
    // NotAllowedError：被自动播放策略拦截
    console.warn("自动播放被拦截，等待用户点击", error.name);
  }
}

tryPlay();
```

## JavaScript 控制接口

```js
const video = document.querySelector("video");

video.play(); // 返回 Promise
video.pause();
video.currentTime = 12.5; // 跳到 12.5 秒
video.playbackRate = 1.25; // 倍速
video.volume = 0.6; // 0 ~ 1
video.muted = true;

video.addEventListener("loadedmetadata", () => {
  console.log("时长", video.duration);
  console.log("尺寸", video.videoWidth, video.videoHeight);
});

video.addEventListener("timeupdate", () => {
  console.log("当前进度", video.currentTime);
});

video.addEventListener("ended", () => {
  console.log("播放结束");
});
```

常用只读属性：`duration`、`currentTime`、`paused`、`ended`、`readyState`、`buffered`。

## 字幕与文字轨道

`<track>` 使用 WebVTT 格式：

```text
WEBVTT

00:00:01.000 --> 00:00:04.000
城市在夜里醒来

00:00:04.500 --> 00:00:08.000
雨后的路面反射着霓虹
```

```html
<video controls>
  <source src="/videos/city-night.mp4" type="video/mp4" />
  <track kind="subtitles" src="/videos/city-night.zh.vtt" srclang="zh" label="中文" default />
  <track kind="captions" src="/videos/city-night.en.vtt" srclang="en" label="English" />
</video>
```

`kind` 常见取值：`subtitles`（翻译字幕）、`captions`（含音效描述）、`descriptions`（画面描述）、`chapters`（章节）。

## 性能与体验

- 长视频用 `preload="metadata"`，不要 `auto`
- 首屏不需要的视频由用户点击后再 `play()`，避免抢带宽
- 给 `<video>` 写死宽高比，防止加载后页面跳动：

```css
.video-wrap {
  aspect-ratio: 16 / 9;
  background: #000;
}

.video-wrap video {
  width: 100%;
  height: 100%;
  object-fit: contain;
}
```

## 小结

- 至少准备 MP4 兜底，WebM 可选
- 自动播放要 `muted` + `playsinline`
- 用 `loadedmetadata` / `timeupdate` 做进度和 UI
- 字幕用 WebVTT + `<track>`，记得给视频容器固定宽高比
