CSS 变量不是 Sass 变量的替代品，它有运行时、可继承、可覆盖的特性，是主题系统的基础。

<!-- more -->

## 声明与使用

```css
:root {
  --color-brand: #2563eb;
  --radius: 8px;
  --space-sm: 8px;
}

.button {
  background-color: var(--color-brand);
  border-radius: var(--radius);
  padding: var(--space-sm) 16px;
}
```

- 变量名区分大小写
- 值可以是任意 CSS 片段，包括其他变量
- 通过 `var(--name, fallback)` 提供回退值

```css
.card {
  color: var(--card-color, var(--color-text));
}
```

## 作用域与继承

自定义属性会继承，在哪个选择器上声明，就作用于它和它的后代：

```css
:root {
  --theme-color: #2563eb;
}

.section--warm {
  --theme-color: #ea580c;
}

.section--warm .button {
  background: var(--theme-color); /* 橙色 */
}
```

这是组件级主题覆写最常用的方式，不需要额外类名。

## 主题切换

```css
:root {
  --bg: #ffffff;
  --text: #111827;
  --border: #e5e7eb;
}

[data-theme="dark"] {
  --bg: #0b0f19;
  --text: #e5e7eb;
  --border: #1f2937;
}

body {
  background: var(--bg);
  color: var(--text);
}
```

```js
document.documentElement.dataset.theme = "dark";
```

再加一段跟随系统的样式：

```css
@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) {
    --bg: #0b0f19;
    --text: #e5e7eb;
  }
}
```

## @property

`@property` 可以声明变量的类型、初始值和是否继承，让变量参与动画计算：

```css
@property --angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}

.ring {
  background: conic-gradient(from var(--angle), #2563eb, #22d3ee, #2563eb);
  animation: spin 4s linear infinite;
}

@keyframes spin {
  to {
    --angle: 360deg;
  }
}
```

没有 `@property` 时，浏览器不知道 `0deg` 是角度，动画会跳变。

## 逻辑属性

用逻辑属性替代方向固定的 `left` / `right`，天然支持 RTL：

```css
.card {
  margin-inline-start: 16px;
  margin-block-end: 24px;
  padding-inline: 20px;
  border-inline-start: 3px solid var(--color-brand);
  inset-inline: 0;
}
```

| 物理属性                 | 逻辑属性              |
| ------------------------ | --------------------- |
| `margin-left`            | `margin-inline-start` |
| `margin-right`           | `margin-inline-end`   |
| `margin-top`             | `margin-block-start`  |
| `padding-left` / `right` | `padding-inline`      |
| `width`                  | `inline-size`         |
| `height`                 | `block-size`          |

## 现代颜色

```css
/* 带透明度 */
.box {
  background: rgb(37 99 235 / 0.12);
}

/* 颜色混合 */
.button:hover {
  background: color-mix(in srgb, var(--color-brand) 85%, black);
}

/* 相对亮度调整 */
.text-muted {
  color: color-mix(in srgb, var(--text) 60%, transparent);
}
```

`color-mix` 让主题色自动派生悬停色、边框色，不用手写一堆十六进制。

## :has 与父选择器

```css
/* 有图片的卡片，图片区域占更大高度 */
.card:has(> img) {
  padding-top: 0;
}

/* 表单里有错误时，整行变红 */
.field:has(input:invalid) {
  border-color: #dc2626;
}
```

`:has` 已经进入基线，可以直接用于生产，但注意别写过于复杂的嵌套。

## 其他常用技巧

### 文本截断

```css
.ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

.clamp-2 {
  display: -webkit-box;
  overflow: hidden;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
}
```

### aspect-ratio

```css
.cover {
  aspect-ratio: 16 / 9;
  object-fit: cover;
  width: 100%;
}
```

### scroll-snap

```css
.carousel {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}

.carousel > * {
  scroll-snap-align: start;
  flex: 0 0 80%;
}
```

### 平滑滚动与锚点

```css
html {
  scroll-behavior: smooth;
  scroll-padding-top: 80px; /* 固定导航高度 */
}
```

### 粘性定位

```css
.toc {
  position: sticky;
  top: calc(var(--nav-height) + 16px);
}
```

## 小结

- 用 CSS 变量组织颜色、间距、圆角，主题切换只改变量
- `var()` 的回退值可以嵌套变量
- `@property` 让变量可动画、有类型
- 逻辑属性面向多语言布局
- `color-mix`、`:has`、`aspect-ratio` 已经可以放心使用
