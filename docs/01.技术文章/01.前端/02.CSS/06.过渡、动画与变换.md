悬停变色用 `transition`，循环漂浮用 `@keyframes`，位移缩放用 `transform`。三者配合，能覆盖绝大多数界面动效。

<!-- more -->

## transition：状态之间的过渡

```css
.button {
  background-color: #2563eb;
  transition: background-color 0.2s ease;
}

.button:hover {
  background-color: #1d4ed8;
}
```

`transition` 只负责「从 A 到 B 的过程」，必须有状态变化触发。

```css
/* 完整写法 */
.card {
  transition-property: transform, box-shadow;
  transition-duration: 0.3s;
  transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
  transition-delay: 0s;
}

/* 简写 */
.card {
  transition:
    transform 0.3s ease,
    box-shadow 0.3s ease;
}
```

注意：`transition: all` 会监听所有属性，容易触发不必要的重绘，尽量写明确属性。

## 缓动函数

| 值                  | 感觉     | 适合             |
| ------------------- | -------- | ---------------- |
| `linear`            | 匀速     | 进度条、循环动画 |
| `ease`              | 缓入缓出 | 默认值，通用     |
| `ease-in`           | 慢起快停 | 离开屏幕         |
| `ease-out`          | 快起慢停 | 进入屏幕         |
| `ease-in-out`       | 两头慢   | 往返运动         |
| `cubic-bezier(...)` | 自定义   | 更自然的物理感   |

推荐几个常用曲线：

```css
--ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
```

## transform

```css
.box {
  transform: translate(10px, 20px) rotate(15deg) scale(1.1);
  transform-origin: center;
}
```

| 函数                        | 作用               |
| --------------------------- | ------------------ |
| `translate(x, y)`           | 平移               |
| `translateX` / `translateY` | 单轴平移           |
| `scale(x, y)`               | 缩放               |
| `rotate(angle)`             | 旋转               |
| `skew(x, y)`                | 倾斜               |
| `matrix(...)`               | 矩阵变换，组合使用 |

多个函数按书写顺序执行，顺序不同结果不同：

```css
/* 先旋转再平移 */
.a {
  transform: rotate(45deg) translateX(100px);
}

/* 先平移再旋转 */
.b {
  transform: translateX(100px) rotate(45deg);
}
```

`translate` 的百分比是相对元素自身尺寸，做居中很方便：

```css
.center {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

## @keyframes 动画

```css
@keyframes float {
  0% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-12px);
  }
  100% {
    transform: translateY(0);
  }
}

.avatar {
  animation: float 3s ease-in-out infinite;
}
```

完整属性：

```css
.avatar {
  animation-name: float;
  animation-duration: 3s;
  animation-timing-function: ease-in-out;
  animation-iteration-count: infinite;
  animation-direction: alternate;
  animation-delay: 0s;
  animation-fill-mode: both;
  animation-play-state: running;
}
```

`animation-fill-mode` 很重要：

- `none`：动画结束后恢复原样
- `forwards`：保持最后一帧
- `backwards`：延迟期间应用第一帧
- `both`：两者都应用

## 性能

会触发重排（layout）的属性：`width`、`height`、`top`、`left`、`margin`。会触发重绘（paint）的属性：`background`、`box-shadow`、`color`。

只有 `transform` 和 `opacity` 通常只走合成（composite），性能最好：

```css
/* 不推荐 */
.card:hover {
  margin-top: -8px;
  transition: margin-top 0.3s;
}

/* 推荐 */
.card:hover {
  transform: translateY(-8px);
  transition: transform 0.3s;
}
```

需要时加提示：

```css
.animated {
  will-change: transform;
}
```

但 `will-change` 会常驻占用内存，动画结束后应移除，不要全局滥用。

## 减少动态效果

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

这是可访问性要求，不是可选项。

## 伪元素做装饰动画

```css
.link {
  position: relative;
}

.link::after {
  content: "";
  position: absolute;
  left: 0;
  bottom: -2px;
  width: 100%;
  height: 2px;
  background: currentColor;
  transform: scaleX(0);
  transform-origin: left;
  transition: transform 0.25s ease;
}

.link:hover::after {
  transform: scaleX(1);
}
```

## 小结

- 状态切换用 `transition`，关键帧动画用 `@keyframes`
- 优先动画 `transform` 和 `opacity`
- 缓动曲线决定动效的「手感」
- 必须处理 `prefers-reduced-motion`
- 不要把 `transition: all` 当默认写法
