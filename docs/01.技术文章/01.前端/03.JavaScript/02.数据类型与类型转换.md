JavaScript 的类型系统以「灵活」著称，也以「迷惑」著称。`1 + "1"`、`[] == false`、`typeof null` 这些结果背后都有明确规则。

<!-- more -->

## 类型总览

原始类型（primitive）共 7 种：

| 类型        | 示例                   | typeof 结果                |
| ----------- | ---------------------- | -------------------------- |
| `string`    | `"abc"`                | `"string"`                 |
| `number`    | `1`、`NaN`、`Infinity` | `"number"`                 |
| `boolean`   | `true`                 | `"boolean"`                |
| `undefined` | `undefined`            | `"undefined"`              |
| `null`      | `null`                 | `"object"`（历史遗留 bug） |
| `symbol`    | `Symbol("id")`         | `"symbol"`                 |
| `bigint`    | `10n`                  | `"bigint"`                 |

引用类型只有一种：`object`，包括普通对象、数组、函数、日期、正则等。

```js
typeof null; // "object"
typeof function () {}; // "function"
typeof []; // "object"
typeof NaN; // "number"
```

判断 `null` 要用显式比较：

```js
const isNull = value === null;
const isObject = value !== null && typeof value === "object";
```

## 原始值与引用值

```js
let a = 1;
let b = a;
b = 2;
console.log(a); // 1

const obj1 = { count: 1 };
const obj2 = obj1;
obj2.count = 2;
console.log(obj1.count); // 2
```

- 原始值按值传递，复制的是副本
- 引用值复制的是地址，两个变量指向同一个对象
- 函数参数也是同样的规则

## 装箱机制

原始值本身没有方法，访问 `"abc".toUpperCase()` 时，引擎会临时创建一个 `String` 包装对象：

```js
"abc".toUpperCase(); // "ABC"

const str = "abc";
str.custom = 1;
console.log(str.custom); // undefined，临时对象用完即销毁
```

显式装箱不推荐：

```js
// 不要这样写
const s = new String("abc"); // typeof 是 "object"
const n = new Number(1);
const b = new Boolean(false); // 注意 Boolean 对象是 truthy

// 用字面量
const s2 = "abc";
```

## 类型转换

### 显式转换

```js
Number("42"); // 42
Number(""); // 0
Number("42px"); // NaN
Number(null); // 0
Number(undefined); // NaN
Number(true); // 1

String(42); // "42"
String(null); // "null"
String(undefined); // "undefined"

Boolean(0); // false
Boolean(""); // false
Boolean(null); // false
Boolean(undefined); // false
Boolean(NaN); // false
```

假值只有 6 个：`false`、`0`、`""`、`null`、`undefined`、`NaN`。其余都是真值，包括 `[]`、`{}`、`"0"`、`" "`。

### 隐式转换

**加号**规则：

1. 任何一边是字符串，另一边也转成字符串
2. 否则两边都转成数字

```js
1 + "2"; // "12"
1 + 2; // 3
true + 1; // 2
[] + 1; // "1"（[] → ""，"" + 1）
[1, 2] + 1; // "1,21"
{
}
+1; // "[object Object]1"
```

其它运算符通常倾向数字：

```js
"5" - 1; // 4
"5" * "2"; // 10
"5" / 2; // 2.5
```

### 对象转原始值

对象参与运算时，引擎会调用 `Symbol.toPrimitive`，没有则依次调用 `valueOf()` 和 `toString()`：

```js
const box = {
  valueOf() {
    return 42;
  },
  toString() {
    return "box";
  },
};

box + 1; // 43，valueOf 优先
`${box}`; // "box"，字符串上下文优先 toString
```

## == 与 ===

`===` 要求类型和值都相同，不做转换。`==` 会先做类型转换：

```js
1 == "1"; // true
1 === "1"; // false
null == undefined; // true
null === undefined; // false
NaN == NaN; // false，NaN 不等于自己

[] == false; // true
[] == 0; // true
[0] == false; // true
"" == 0; // true
```

`==` 的转换规则简化版：

- `null` 只和 `undefined` 相等
- 数字和字符串比较时字符串转数字
- 布尔值先转数字
- 对象和原始值比较时对象转原始值
- `NaN` 和任何值都不相等

除了 `value == null` 这种判空写法，其余一律用 `===`。

## Object.is

`Object.is` 和 `===` 基本一致，但有两个例外：

```js
Object.is(NaN, NaN); // true
Object.is(0, -0); // false

NaN === NaN; // false
0 === -0; // true
```

React 等库用它做状态比较。

## 数值细节

```js
0.1 + 0.2; // 0.30000000000000004
0.1 + 0.2 === 0.3; // false

Number.isInteger(1.0); // true
Number.isNaN(NaN); // true
Number.isNaN("NaN"); // false，比全局 isNaN 安全
Number.isFinite(Infinity); // false
Number.parseFloat("3.14px"); // 3.14
Number.parseInt("42abc", 10); // 42
```

金额计算不要直接用浮点数，用整数分或专门的十进制库。

## 小结

- 记住 7 种原始类型和 `typeof null` 的历史 bug
- 假值只有 6 个
- `+` 遇到字符串就拼接，其它算术运算符倾向转数字
- 判等默认用 `===`，判空可以用 `value == null`
- 浮点数不精确，金额用整数运算
