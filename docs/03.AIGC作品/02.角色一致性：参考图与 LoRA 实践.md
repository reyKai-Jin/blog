AI 短片里最头疼的问题之一：同一个角色，换一个镜头就换了张脸。这篇记录我目前验证过的几种一致性方案。

<!-- more -->

## 问题拆解

角色一致性可以拆成三层：

1. **面部**：五官、发型、肤色是否稳定
2. **服装**：同一套造型在不同镜头是否一致
3. **气质**：表情、体态、镜头语言是否像同一个人

只解决第一层，角色依然会「串味」。

## 方案一：角色设定图

先生成一张角色设定图（三视图或半身像），把它作为后续所有生成的参考。

要点：

- 设定图尽量干净，背景简单
- 明确发型、服装、配饰等关键特征
- 保存好这张图，它是整个项目的「锚点」

## 方案二：参考图 + 固定种子

在生成时同时提供角色参考图，并固定随机种子，能在一定程度上保持面部稳定。

适合场景：镜头不多、风格统一的短片。

局限：换动作或换视角时，稳定性会明显下降。

## 方案三：LoRA 训练

如果角色会贯穿整个项目，值得训练一个 LoRA。

流程：

```text
挑选素材（15–30 张，多角度、多表情）
   ↓
打标（统一触发词 + 关键特征描述）
   ↓
训练（注意过拟合）
   ↓
测试不同权重下的稳定性
```

经验：

- 素材质量比数量重要
- 触发词要唯一，避免和通用词冲突
- 权重不要拉满，保留一点模型的泛化能力
- 训练后一定要做多场景测试，而不是只看训练集

## 方案四：后期统一

即使前期做得再好，后期也需要统一：

- 统一肤色和色温
- 统一锐化和颗粒
- 必要时对脸部做轻量修复
- 用相同的调色预设收尾

## 我的取舍

| 项目规模 | 推荐方案 |
| --- | --- |
| 单镜头 / 静态图 | 参考图 + 固定种子 |
| 3–5 个镜头 | 角色设定图 + 参考图 |
| 完整短片 | LoRA + 设定图 + 后期统一 |

一致性不是某一个技巧，而是**一整套约束**。把参考、种子、提示词和后期都固定下来，角色才真正「活」在同一部片子里。
