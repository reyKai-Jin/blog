## 创作说明

想拍的不是「城市有多繁华」，而是繁华退场后的安静。所以全片刻意避开了人群和正脸，只用背影、局部和反光来交代人物。

## 拍摄参数

| 项目     | 设置                            |
| -------- | ------------------------------- |
| 机身     | 全画幅微单                      |
| 镜头     | 24mm F1.4 / 50mm F1.8           |
| 帧率     | 4K 25p（慢动作段落 1080p 100p） |
| 快门     | 1/50s（跟帧率匹配）             |
| ISO      | 800–6400                        |
| 白平衡   | 3800K，保留冷暖对撞             |
| 色彩模式 | Log，便于后期调色               |

## 分镜思路

1. **建立环境**：地铁出口、便利店灯牌、湿漉漉的路面。
2. **人物入场**：只拍脚步、手、侧影，保持距离感。
3. **情绪推进**：车流延时、霓虹特写、玻璃反射。
4. **收尾**：人物走向画面深处，声音先于画面淡出。

## 剪辑

- 节奏：前 30 秒慢，中段用延时和跳切提速，结尾再慢下来。
- 转场：尽量用运动匹配和遮挡转场，少用花哨特效。
- 卡点：音乐的重音落在车流延时和霓虹闪烁上。

## 调色

- 整体压暗高光，保留灯牌的层次。
- 阴影偏青蓝，高光偏橙，制造冷暖对比。
- 降低整体饱和度，只让霓虹和肤色保持相对鲜艳。
- 加少量颗粒，避免数码感太干净。

## 声音设计

- 环境声：地铁、雨声、远处车流。
- 音乐：低频铺底 + 中段加入节奏。
- 细节：脚步、开关门、玻璃反光时的轻微电流声。

## 复盘

- 夜景高 ISO 的噪点比预期明显，下次会带补光或更亮的镜头。
- 手持段落还是有点抖，稳定器准备不足。
- 剪辑时素材量偏少，转场选择受限，下次按分镜多拍 30% 的备选镜头。
